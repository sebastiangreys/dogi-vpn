Descarga Dogi

Obtén la versión para Windows desde esta página. El botón descargará el archivo cuando publiques DogiSecuritySystem.exe junto a esta página.

Importante: el archivo DogiSecuritySystem.exe se crea en Windows con el script de compilación incluido. Debes probarlo antes de publicarlo.
↓ Descargar instalador

Cómo instalarlo

1. Descarga el archivo EXE desde el botón.
2. Comprueba que el archivo provenga de una fuente de confianza.
3. Ábrelo y sigue las instrucciones del instalador.
4. Si Windows muestra una advertencia, verifica el editor y el origen antes de continuar.

Esta descarga es la aplicación EXE, no un instalador con asistente. Dogi no sustituye a un antivirus completo. La app requiere ClamAV instalado y configurado en la ruta indicada por el programa.
